# Streamlining-Military-Asset-Management-with-ASP.NET-Core-MVC
During my military service, I noticed a major operational problem — tracking hundreds of IT devices (laptops, printers, screens) across multiple military branches was done manually. Paper logs, outdated records, zero visibility.

So I built Nozom (نظم) — a full-stack web application to solve exactly that.

📦 Track every device — type, brand, model, serial number & operational status
📍 Know exactly where every device is at all times across all branches
🔄 Full movement history — who moved it, from where, to where, and when
🛠️ Maintenance log — records the soldier who brought the device & who received it
🔐 Secure login system — only authorized personnel can access the data
Tech stack:

ASP.NET Core MVC
Entity Framework Core
SQL Server
ASP.NET Identity
Repository Pattern
Bootstrap
What made this special? I didn't build it for a portfolio. I built it because it was actually needed — and it was used in a real operational environment.

This taught me more than any tutorial ever could. Real users. Real constraints. Real impact. 💪
